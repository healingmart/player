# HealingMart mandatory font policy
All agents must read [font policy](https://github.com/healingmart/healingmart-cloudflare-guide-test/blob/policy/pretendard-20261028/FONT_POLICY.md). Korean/English: **self-hosted Pretendard Variable**, SIL OFL 1.1. Other languages: verified, self-hosted Noto Sans variants with license notice. Never add paid/unlicensed fonts, Malgun Gothic/맑은 고딕, Arial, Segoe UI, Apple SD Gothic Neo, Georgia, Times New Roman, Consolas, etc. No CDN-only fonts. Install a font audit before builds/deployments; no production deployment or new GitHub Actions for this change.
